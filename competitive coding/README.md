| Keyword    | Use              |
| ---------- | ---------------- |
| subarray   | prefix / sliding |
| k times    | heap             |
| max/min    | greedy           |
| frequency  | Counter          |
| duplicates | set/dict         |

## 1.n ≤ 10^5
cannot use O(n²)

## 2.n ≤ 500
brute force OK
